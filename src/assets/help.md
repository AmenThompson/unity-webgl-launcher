## 预览 Unity 项目

1. 在 Unity 中将平台切换到 WebGL，构建到单独的目录。
2. 在启动台选择包含 `index.html` 的导出目录，或选择其中的入口文件。保留 `Build` 与 `TemplateData` 等配套资源的原相对路径。
3. 启动器自动识别 Brotli、Gzip 和 Disabled（未压缩），并显示 Decompression Fallback 状态。直接使用已有的发布目录即可。
4. 选择 **启动并打开**。预览将在 Windows 默认浏览器中打开，可在启动台复制预览地址或停止服务。

## 多线程与故障排查

- 仅当 Unity 构建启用了线程时打开 **多线程支持**。启动器会发送跨源隔离响应头。若浏览器仍提示 `SharedArrayBuffer` 不可用，请检查项目加载的外部脚本、媒体和其它资源是否支持跨源隔离。
- 如果有文件无法加载，请确认导出目录完整。对于使用自定义命名或加载器的项目，格式可能显示「未识别」。运行日志和浏览器控制台可用于检查资源错误。
- **运行内置诊断** 可验证当前默认浏览器的 WebGL 能力，适合在没有 Unity 项目时检查预览环境。
- 停止服务后预览地址会失效。项目路径和多线程选项会保存在本机。
